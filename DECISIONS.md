# MakerMesh decisions

## 2026-08-29 — Independent repository

MakerMesh lives in its own Git repository under `webcafe-ai/makermesh`. No parent
Webcafe code is reused or modified.

## 2026-08-29 — Demand-first ceramics wedge

The hackathon scope is custom Moroccan ceramics for small businesses. General-purpose
marketplace features remain out of scope until the controlled espresso-cup loop works.

## 2026-08-29 — Evidence and evaluation boundary

OpenAI may structure and explain information. Deterministic TypeScript evaluates
requirements and ordering. Unknowns never earn points or become implicit passes.

## 2026-08-29 — Reputation-safe public suppliers

Identifiable real suppliers may appear with public facts, links, and unknowns, but not
public negative grades, qualification failures, comparison scores, quotes, or passports.
The fictional Atlas Clay Studio carries the complete decision and email demo.

## 2026-08-29 — Public demo isolation

Use one immutable sanitized baseline plus expiring per-session overlays rather than
copying the entire project for each visitor. The target overlay lifetime is 24 hours.

## 2026-08-29 — Genuine operator authentication

Privileged operations use a custom Convex Auth credentials provider with server-only
PBKDF2 verification, rate-limited login, short-lived signed sessions, an indexed operator
profile, and authorization checks at every privileged boundary. Signed Convex Auth
tokens are the approved Vite-compatible equivalent to an HttpOnly session cookie.

## 2026-08-29 — Licence boundary

MIT covers application source code only. Brand, imagery, fixtures, supplier content, and
third-party assets are excluded unless explicitly licensed in `CREDITS.md`.

## 2026-08-29 — Scoped external work and reply provenance

Every paid operation is scoped by provider, project, current brief, material-input hash,
attempt, and lease. Inbound mail must match the configured inbox, controlled sender,
approved draft, and current brief. Email-derived answers and quote fields persist only
with exact excerpts from the hashed analyzed message.
